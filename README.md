# agent-skills

Reusable agent and skill assets for openEuler automation workflows.

## Skill Sets

- `import-pkg/`: Package introduction workflow skills.
- `cve-fix-skill/`: CVE fix analysis, matching, patching, verification, and submission skills.
- `upgrade-ros-pkg/`: AI-assisted openEuler ROS package upgrade workflow based on `openeuler-ros-upgrader`.
